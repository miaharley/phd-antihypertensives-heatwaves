# Antihypertensives and heatwaves (Japan)

This repository contains the code and codelists accompanying the antihypertensives and heatwaves study conducted as part of my PhD thesis.

## Repository structure

- `code/` – Stata scripts used to create the study cohort and perform the statistical analyses.
- `codelists/` – Clinical codelists used in the study.

## Data

The underlying Japanese healthcare data cannot be shared publicly due to data governance restrictions. This repository contains only the analysis code and supporting codelists.
